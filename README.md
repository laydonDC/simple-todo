# Simple To-Do App (MERN)

A simple and responsive To-Do application built using the **MERN stack**.  
This project includes a React frontend and a Node.js + Express + MongoDB backend.

---

## 🚀 Live Demo
**https://simple-todo-one-wine.vercel.app/**

---

## 📦 Tech Stack
- MongoDB  
- Express.js  
- React  
- Node.js  

---

## ✨ Features
- Add tasks  
- Delete tasks  
- Mark tasks as completed  
- Responsive UI
